# Matcha_42
Because love, too, can be industrialized.

# Tech Stack Selection

This stack is selected for Maximum Safety (Passing the project) + Maximum Learning.

Layer	     |   Technology                                           |   Why this choice?
Language     |   TypeScript                                           |   Catch bugs early. "Must-have" for 2026 jobs.
Backend	     |   Express.js                                           |   The definition of a micro-framework. No magic, just routing.
Database     |   PostgreSQL                                           |   The industry standard. You will write raw SQL.
DB Driver	 |   pg (node-postgres)	                                  |   The raw driver. You will build your wrapper around this.
Frontend	 |   React + Vite	                                      |   Fast, standard, separate from backend (clean architecture).
Styling	     |   Tailwind CSS	                                      |   Rapid UI development. Handles "Mobile Friendly" easily.
Realtime	 |   Socket.io	                                          |   Easier than raw WebSockets for handling rooms/events.
Validation	 |   Zod                                                  |   External library (allowed). The modern standard for schema validation.
Ops	         |   Docker, compose, Nginx, sops, age, makefile, shell	  |   Simulates a real production environment.
